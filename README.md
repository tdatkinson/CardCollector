# CardCollector Marketplace

A front-end Angular prototype for a collectible card marketplace, featuring:

- customer-facing shopping pages
- account and order history views
- admin dashboard and inventory tools
- reusable catalog/filter components
- mock marketplace data and routing

## Live Demo

https://tdatkinson.github.io/CardCollector/

## Local Development

```bash
npm install
npm start
```

Then open:

```text
http://localhost:4200/
```

## GitHub Pages Deployment

```bash
npm run deploy
```

This builds the Angular app using the GitHub Pages base URL and publishes the output to the `gh-pages` branch.

## Project Notes

This is a front-end prototype only. It does not include backend services or database integration.
